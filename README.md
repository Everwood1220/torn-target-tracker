# Torn Target Tracker

A war target tracker for [Torn City](https://www.torn.com). Live hospital timers, chain, war score and push alerts, all in one page.

**Open it:** https://everwood1220.github.io/torn-target-tracker/

## What it does
- Tracks your target list: status, life, hospital/jail time and reason, last action, and your win/loss history with each player.
- Hospital countdowns synced with Torn's clock, with an "Out for" timer when a target comes out.
- Top bar with your energy, nerve, life, status and cooldowns, ranked war score, chain count and timeout, and Torn City Time.
- **Push** countdown and **STAY IN HOSP** alert read from your Torn message subjects (e.g. "Push @ 18:30", "Turtle").
- Load targets from a Google Sheet, a faction page, player IDs, or a JSON / CSV file, and keep saved lists.

## Your API key is safe
- Use a **Limited Access** key (Torn → Settings → API Keys).
- The key is saved only in **your own browser** and sent only to Torn's official API. There is no server, no tracking and no outside scripts.
- Torn API keys are read-only, so this page can't attack, spend, trade or send anything for you.
- The key is deleted automatically after 7 days of not using the page, and Settings has **Erase everything** to wipe all saved data.
- All the code is in `index.html` in this repo, so anyone can check it.

Torn Item Seller - Release Notes
================================

v0.1 - NOT RELEASED YET
- First build: lists your inventory with Torn market value, lowest item market price,
  listing count, suggested price (lowest minus undercut), total value and price age.
- Copy suggested price, View market link per item, Add listing / Bazaar add shortcuts.
- Price queue (650 ms spacing) with progress, per-row refresh, Refresh all, Stop.
- Hides equipped, faction-owned and untradable items (toggle to show).
- Search, category filter, sortable columns.
- My item market listings, flagged when above the current lowest price.
- Limited Access key stored only in this browser; change/delete key; Erase everything.
- Fix: inventory load failed with "Torn API error 21: Incorrect category". The inventory is
  now loaded one category at a time (about 25 calls, 650 ms apart) and the results are merged.
- The API key is now sent as ?key= on each call (the standard Torn method).
- Removed the Suggested column (Copy still copies the lowest price minus the undercut).
- New favicon: green dollar sign.

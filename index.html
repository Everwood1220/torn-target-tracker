Enter your Torn API key

Get it from your Torn settings → API Keys and create a Limited Access key. It lets this page:

  • Check each target's status, life, hospital time and last action
  • Show your energy, nerve, life, status and drug, booster and medical cooldowns
  • Show the chain count and timeout, and your faction's ranked war score
  • Read your attack log for the win/loss History with each player
  • Read the subjects of your Torn messages for the Push timer and STAY IN HOSP alert (nothing is opened or marked read)

A Public key can't read your own info, so most of this, including History and the Push alerts, wouldn't work. Torn API keys are read-only, so this page can't attack, spend, trade or send anything for you.

🔒 Your key never leaves your computer
  • It's saved only in this browser on this device. There's no server, account or database behind this page, and nobody else (including the page's author) can see it.
  • Your browser sends it straight to Torn's official API (api.torn.com) and nowhere else.
  • The whole page is open source on GitHub, so anyone can check this.
  • Want proof? In Torn's API Keys page, open this key's log. Every call comes from your own internet (IP) address, because the requests are made by your browser, not by an outside server.
  • You're always in control. Delete it here anytime, use Erase everything in Settings, or turn it off in Torn's API Keys page. By default, a key unused for 7 days is deleted automatically.
  • Tip: create a new key just for this page and name it something like "Target Tracker" in Torn. That way you always know what it's for, and you can delete it anytime without affecting your other tools.
